# ApplyFlow

ApplyFlow is a production-oriented REST API for managing and tracking job applications.

Users can manage companies, vacancies, applications, and interviews through a RESTful API.

## Features

- User registration and authentication
- JWT authentication
- Company management
- Vacancy management
- Job application tracking
- Interview tracking
- Filtering and search
- User-specific data access
- Validation and permissions
- Automated tests

## Tech Stack

- Python
- Django
- Django REST Framework
- PostgreSQL
- Simple JWT
- pytest
- pytest-django
- Docker
